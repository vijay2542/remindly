## ⚡ Quick Start

### 1. Launch Android Emulator
```bash
flutter emulators --launch Pixel_8
```

### 2. Run Application
```bash
flutter run
```

### 3. Build Release APK
```bash
flutter build apk --release
```
**Output APK**: `build/app/outputs/flutter-apk/app-release.apk`
